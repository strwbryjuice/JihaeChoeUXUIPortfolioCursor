Project Overview
Summary

This is a passion project I started to practice my AI and front-end coding skills while contributing to the community. It is a community-based project that invites non-designers to create their own fonts.

Participants draw the alphabet by hand, and their drawings are converted on the spot into a typeable digital font. As a token of gratitude for participating, each participant receives a zine that is also printed on site.

Thank you to Market Root, Rhizomatic, Create Space London, Kindred Studio, Bremen Zine Festival, Tagore’s Salon (+ Set91), and Glasgow Zine Library for accepting my proposal and providing venues and relevant materials.

FindingAn average of 12 minutes of downtime occurred during printing.

Finding 03
Giving participants control over submissions
FindingIt was sometimes unclear which letter a drawing represented—for example, an uppercase “M” or a lowercase “m.” Manually uploading each participant’s drawing also pulled my attention away from facilitating the workshop and observing their reactions.
ChangeI built a local Python server and a mobile upload flow so participants could submit their drawings directly from their phones and preview the processed images.
How I used AI

I connected REA to Codex and used it to adapt image-processing techniques from the free features of a scanning app, integrating them into my existing front end. With no prior backend experience, I also worked with Claude through an iterative conversation to build a local Python server that supported mobile submissions during workshops.

Reflection

However, the setup still requires everyone to be on the same Wi-Fi. When a venue does not provide Wi-Fi, I use my mobile hotspot, which currently supports only my laptop and three participants’ phones at a time. My next step is to adapt the code and move to an online server so participants can join using their own mobile data, without needing to be on the same Wi-Fi.
